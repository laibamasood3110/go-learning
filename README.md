# Go Practice

My journey learning the Go programming language. This repo holds the exercises I write while learning, and I add to it as I go.

## Topics covered so far
Variables, functions, loops, range, structs, maps, and basic program structure.

## Exercises
- `simplegradecalculator.go`: a simple grade calculator
- `loop-practice`: practice with for loops
- `range-practice`: looping with range
- `mapspractice`: working with maps
- `maps-struct`: combining maps and structs
- `employee-struct`: a struct for employee data
- `struct-student`: a struct for student data
- `fictorial`: factorial practice
- `traffic-light`: a traffic light program
- `ticket-pricing-system`: ticket price logic
- `library-book-checker`: checking library books
- `employee-management-system`: managing employee records
- `student-result-management-system`: managing student results
- `employe-management-system-pointers`: same program rewritten with pointer receivers
- `pointers-practice`: practice with pointers
